# Migração e preservação

Este diretório documenta a passagem do WordPress para o site estático.

Regra operacional: **preservar primeiro, reorganizar depois, melhorar por último**.

O conteúdo bruto extraído do WordPress deve permanecer distinguível do conteúdo convertido para Astro. Nenhum texto deve ser apresentado como cópia do WordPress se tiver sido apenas resumido, reescrito ou reconstruído.
