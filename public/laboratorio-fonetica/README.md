# Laboratório de Fonética da UFAL — website editorial

Escopo isolado de `public/laboratorio-fonetica/` no repositório fonUFAL/fonUFAL.

Páginas: Home, Infraestrutura e Equipe, em português e inglês.

A equipe lista apenas Miguel Oliveira Jr. como responsável confirmado. Equipamentos listados resultam de inventário parcial; não pressupor unidades, estado de manutenção ou política de reserva. Projetos de fonUFAL e Lapelc² não foram apropriados como atividades do laboratório.

Imagens: recortes de pranchas de direção de arte produzidas para este projeto (ilustrativas; não fotografias documentais). O site não utiliza fotografias do interior real do laboratório.

Visual: verde profundo, sálvia, ameixa, coral queimado e creme; tipografia Fraunces/DM Sans/DM Mono.
